    • 📋 Visão Geral do Projeto

    Desenvolvimento de duas calculadoras científicas funcionalmente equivalentes, implementadas em paradigmas distintos para análise comparativa.

    🔧

    Paradigma Funcional

    Haskell - Linguagem puramente funcional com avaliação lazy e sistema de tipos forte

    🧠

    Paradigma Lógico

    Prolog - Programação declarativa baseada em fatos, regras e unificação

    📈 Curva de Aprendizado

    ⚡ Funcionalidades Implementadas

  • Operações Básicas: Adição, Subtração, Multiplicação, Divisão
  • Precedência de Operadores: Respeita ordem matemática padrão
  • Suporte a Parênteses: Expressões aninhadas e agrupamentos
  • Números Decimais: Processamento de ponto flutuante
  • Tratamento de Erros: Detecção de divisão por zero
  • Interface Interativa: Modo REPL (Read-Eval-Print Loop)
  • Parsing Robusto: Análise sintática de expressões matemáticas
  • Instalação Automatizada: Scripts para configuração do ambiente

    • 🔧 Implementação Haskell (Funcional)

    data Expr = Val Double | Add Expr Expr | Sub Expr Expr | Mul Expr Expr | Div Expr Expr eval :: Expr -> Maybe Double eval (Val n) = Just n eval (Add x y) = (+) <$> eval x <*> eval y eval (Div x y) = do dy <- eval y if dy == 0 then Nothing else do dx <- eval x return (dx / dy)
    ~80

    ⚖️ Vantagens e Desvantagens

    🔧 Haskell (Funcional)

    ✅ Vantagens

    • Type safety robusto
    • Controle total do fluxo
    • Código altamente modular
    • Otimizações do compilador
    • Paralelização natural

    ❌ Desvantagens

    • Curva de aprendizado íngreme
    • Maior verbosidade inicial
    • Debugging complexo
    • Menos bibliotecas práticas

    🧠 Prolog (Lógico)

    ✅ Vantagens

    • Implementação extremamente concisa
    • Recursos built-in poderosos
    • Prototipagem rápida
    • Expressividade declarativa
    • Ideal para IA/Expert Systems

    ❌ Desvantagens

    • Performance limitada
    • Debugging não-intuitivo
    • Controle de execução limitado
    • Menos type safety

    🧠 Prolog

    ?- [calculator].
    true.
    ?- start.
    Digite uma expressão:
    2+3*4.
    Resultado> 14
    sair.
    Encerrando a calculadora. 👋

    Ambas implementações oferecem a mesma funcionalidade com interfaces similares,
    mas com arquiteturas completamente diferentes!

    🧪 Teste Interativo

    Essa avaliação é feita com JavaScript e serve apenas para fins ilustrativos. Sem tratamento de segurança avançado.

    🎯 Conclusão

    O estudo comparativo entre paradigmas evidenciou:

    • 🧠 Paradigma lógico (Prolog) brilha em expressividade declarativa e concisão.
    • 🔧 Paradigma funcional (Haskell) oferece robustez, segurança e clareza estrutural.
    • 🧪 A lógica da calculadora se manteve consistente, apesar das abordagens radicalmente diferentes.
    • ⚙️ Cada paradigma exige um mindset único — um verdadeiro exercício de elasticidade mental!
