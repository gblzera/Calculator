# Executando o Arquivo `calculator.lua`

Para executar o arquivo `calculator.lua`, siga os passos abaixo:

1. Certifique-se de que você possui uma versão do Lua instalada em seu computador.
2. Navegue até o local onde o arquivo `calculator.lua` está armazenado.
3. Abra o PowerShell ou terminal na pasta onde o arquivo está localizado.
4. Execute o seguinte comando:

```bash
lua54 calculator.lua
```

Substitua `lua54` pela versão do Lua instalada no seu sistema, caso seja diferente. O formato geral do comando é:

```bash
lua<versão_do_lua> nome_do_arquivo.lua
```
